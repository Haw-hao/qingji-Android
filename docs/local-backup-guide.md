# 本地自动备份与恢复

适用版本：轻记 0.3.4 起。

## 首次启用

1. 进入“我的”→“本地自动备份”→“选择本地备份目录 / 恢复”。
2. 在系统文件选择器中选择手机本地目录，建议新建 `Documents/轻记备份` 子文件夹，再点“使用此文件夹”并允许访问。
3. 返回后确认显示“已开启”和“最近成功备份”时间。如果显示错误，先解决错误；不能把“已选择目录”视为备份已成功。

新增、删除账单，账户及自定义分类变更后会自动备份。备份包含所有账单、账户名称与初始余额、自定义分类。开启自动入账时，自动写入的账单也会触发备份。

备份在后台串行写入，完成后保留最近两份成功快照；也可以点“立即备份”。卸载前应等待备份完成，并核对最近成功时间。文件写入错误会显示在设置页，已有有效备份不会被未完成的新文件覆盖。

## 卸载重装后恢复

正常卸载应用不会删除用户选择的共享文档目录，但应用的目录授权会失效。

1. 安装新版后进入“我的”，再次选择**原来的同一备份目录**并允许访问。
2. 应用显示找到的最新有效备份时间、账单数量和账户数量。
3. 核对信息后点“确认恢复并开启备份”。恢复会替换当前应用内账单、账户和自定义分类，不会合并；取消则不改变当前账单。

恢复前不会用新安装的空账本覆盖旧备份。文件读取后会检查格式版本、SHA-256、金额、日期、ID和账户关联；损坏的文件不会直接写入账本。有较新的损坏文件时会寻找较早的有效快照；如果没有有效快照，显示错误并保留原文件。

## 范围与限制

- 文件只写到所选目录，没有新增云上传功能。系统选择器请求仅显示本地位置。
- JSON 文件包含明文账单，请自行管理目录和文件访问。
- 备份不是系统缓存；正常卸载后保留，但手动删除目录、存储清理或手机重置仍可能丢失，应另行保存重要备份。
- 目录被移动、授权撤销、磁盘已满时，自动备份可能失败。后台尚未完成的写入不能保证在强制停止或断电前保存。
- “停用自动备份”只停用后续写入，不删除已经生成的备份。
- 本功能无法恢复启用备份前已经因卸载而删除的账单。
